# AI价值迁徙实时表盘

这是一个基于 AVCM 框架的 AI 产业信号追踪表盘，用来持续观察“价值是否正在从模型层迁徙到两端”。

## 表盘的作用

它不是荐股工具，也不是一次性的 benchmark 展示页，而是一个叙事迁徙探测器：

- 把 GLM-5.2、Cursor、算力扩建、Agent 基础设施融资、主权 AI 等分散新闻放进同一张观察框架。
- 用层级、证据等级、状态、信心分、影响分来区分事实、传闻和个人判断。
- 帮助复盘“模型商品化”“入口捕获”“算力上游”“Agent 基础设施前置”“主权 AI”这些判断是否成立。
- 通过筛选、KPI、热度图和事件流，观察资金、注意力、用户时间和基础设施建设正在流向哪里。

## AVCM 层级

- `M-模型层`：基础模型与细分能力本身，重点观察开源追赶、API 价格、真实任务稳定性。
- `A-应用/入口`：IDE、聊天入口、工作流和记忆系统，重点观察用户时间和切换成本。
- `C-算力/能源`：GPU、数据中心、电力和推理基础设施，重点观察上游租金与 CAPEX。
- `I-Agent基础设施`：身份、支付、权限、合规、观测性，重点观察 Agent 经济的水电煤。
- `S-主权AI`：安全体系、政府采购、监管认证，重点观察非商业定价逻辑。
- `V-价值/信任锚`：生态默认标准、企业信任、监管认可，重点观察谁成为默认可信底座。

## 使用方式

直接打开 `index.html` 即可使用。

- 左侧筛选层级、状态、证据强度和时间范围。
- 点击“新增信号”记录新的观察。
- 点击“模拟新信号”查看实时事件流效果。
- 点击“导出 CSV”导出当前筛选后的事件。
- 数据保存在浏览器本地存储中，刷新页面不会丢失。

## 适合的复盘节奏

- 每周：补充新事件和来源。
- 每月：检查各层热度、影响分和待验证比例。
- 每季度：复盘原始判断是否被证据支持，记录偏差来源。
- 三年后：回看这些判断到底是先知，还是又一次踩坑。
